# Models and effort

| Tier | Effort | Use for |
|---|---|---|
| haiku | medium | Lookups, search, mechanical edits |
| sonnet | high | L1 implementation and L1 review, normal tickets, fix rounds |
| opus | high | Architecture, cross-module implementation, every L2+ review, reflection judgment |

Rules:

1. The reviewer's tier is never below the implementer's tier.
2. Implementer and reviewer are always different agents, each with fresh context.
3. L4 work and contested designs get an extra cross-family review pass through Codex when the codex plugin is present and contributor mode is off.
4. Fable only when the user asks for it.
5. Lane and tier may come from Jev (see [jev.md](jev.md)); otherwise classify yourself with this table.
